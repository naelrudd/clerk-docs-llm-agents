# Upgrade guides overview

Upgrade your application to newer versions of Clerk by following the guides found in the sidenav.

Also be sure to read our [long term support policy](https://clerk.com/docs/guides/development/upgrading/versioning.md#long-term-support-policy) to understand which level of support for your version you can expect.

If you run into problems while upgrading, [contact support](https://clerk.com/contact/support){{ target: '_blank' }}.

## API versions

For a list of all the available API versions and information about versioning, see the [dedicated guide](https://clerk.com/docs/guides/development/upgrading/versioning.md#api-versions).
