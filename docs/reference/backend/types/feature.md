# Feature

> Billing regularly introduces new features and UI changes to Clerk's components. If you'd like to remain on a specific version of Clerk's components or SDK, you can follow the steps in the [pinning](https://clerk.com/docs/pinning.md) documentation.

The `Feature` object represents a Feature of a Subscription Plan.

## Properties

| Property                               | Type                       | Description                                 |
| -------------------------------------- | -------------------------- | ------------------------------------------- |
| <a id="avatarurl"></a> `avatarUrl`     | `null | string` | The URL of the Feature's avatar image.      |
| <a id="description"></a> `description` | `null | string` | The description of the Feature.             |
| <a id="id"></a> `id`                   | `string`                   | The unique identifier for the Feature.      |
| <a id="name"></a> `name`               | `string`                   | The name of the Feature.                    |
| <a id="slug"></a> `slug`               | `string`                   | The URL-friendly identifier of the Feature. |
